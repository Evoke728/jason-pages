官方 Skill
Anthropic 官方 skills repo 裡的 skill　→　用上面的第 2、3 行裝
Superpowers
superpowers plugin 內附的 skill　→　用上面的第 4 行裝
官方 Plugin
Anthropic plugin 目錄裡的獨立 plugin　→　各項目附完整指令，點複製即可
Plugin 跟 Skill 不是同一個東西
Skill 是一份 SKILL.md 指示文件；Plugin 可以同時包含 skills、commands、agents、hooks 和 MCP server。裝 plugin 通常會一次帶進好幾個能力。

01frontend-design官方 Skill
處理 AI 生成前端長得都一樣的問題。設計目標明確寫著要避開 Inter 字體、紫色漸層、圓角卡片、置中排版這一套 AI 預設美學。用在需要有設計主張的頁面，不是只要能跑就好的內部工具。
02web-artifacts-builder官方 Skill
做需要狀態管理、路由、多元件的複雜 artifact。跟單檔 HTML/JSX 的差別在於它假設你要做的是一個應用，不是一個片段。支援 React、Tailwind、shadcn/ui。
03theme-factory官方 Skill
輸入幾個主色，產出完整的色階系統。省掉手動調 50 到 900 每一階的時間。
04brand-guidelines官方 Skill
把品牌色與字級規範載入，套用到任何產出上，包含簡報、文件、報告、HTML 頁面。預設帶的是 Anthropic 自己的品牌設定，你可以照著結構改成自己的。最大的價值是當範本用——看它怎麼把一套品牌規範寫成機器讀得懂的格式。
05canvas-design官方 Skill
輸出可編輯的向量圖，不是點陣圖。做完之後可以進 Figma 或 Illustrator 繼續改。
06webapp-testing官方 Skill
用瀏覽器實際打開頁面測試，看畫面到底長什麼樣，而不是只看程式碼推測。
07playwright官方 Plugin
Microsoft 出的瀏覽器自動化 MCP server。讓 Claude 可以真的操作網頁：截圖、填表單、點按鈕、跑端對端測試。跟 webapp-testing 搭著用，一個負責測試方法，一個負責實際操作瀏覽器。
/plugin install playwright@claude-plugins-official
08project-artifact官方 Plugin
把專案現況做成一個可分享的 claude.ai artifact 頁面，包含專案概覽、成功條件、工作流順序、下一步。每次重新整理會重新抓最新狀態並重新部署。適合拿來當專案的對外進度頁。
/plugin install project-artifact@claude-plugins-official
09code-simplifier官方 Plugin
在不改變功能的前提下，把程式碼整理得更清楚、更一致、更好維護。它會針對最近改動過的部分下手，不會整包翻。
/plugin install code-simplifier@claude-plugins-official
10code-modernization官方 Plugin
改寫老舊程式碼，包含 COBOL、舊版 Java/C++、單體式網頁應用。流程分成盤點、評估、對照、抽出規則、重新設計、轉換、加固幾個階段，附帶互動式架構檢視器。這是重型工具，小專案用不到。
/plugin install code-modernization@claude-plugins-official

22skill-creator官方 Skill
生成新的 skill。會引導你把一段重複的工作寫成 SKILL.md 的標準結構。判斷標準很簡單：同一段 prompt 你在不同對話裡打過三次以上，就該做成 skill。
23plugin-dev官方 Plugin
開發 Claude Code plugin 的完整工具包，內含 7 個 skill，涵蓋 hooks、MCP 整合、commands、agents 與最佳實踐，含建立與驗證流程。做完 skill 想打包發佈給別人裝，用這個。

24hookify官方 Plugin
建立自訂 hook 來擋掉不想要的行為。可以分析對話模式自動生成規則，也可以直接下明確指令，規則用 markdown 檔定義。例：你不想讓它每次都自動 commit，寫成 hook 規則就不會再發生。
/plugin install hookify@claude-plugins-official
25claude-md-management官方 Plugin
維護 CLAUDE.md 的工具：檢查品質、把這次對話學到的東西寫回去、讓專案記憶保持在最新狀態。CLAUDE.md 會隨專案長大而腐化，這個 plugin 就是處理這件事。
/plugin install claude-md-management@claude-plugins-official
26claude-code-setup官方 Plugin
分析你的 codebase，反過來建議你這個專案該裝哪些 hooks、skills、MCP servers、subagents。新專案開場先跑這個，比自己憑感覺挑快。
/plugin install claude-code-setup@claude-plugins-official
27session-report官方 Plugin
讀取本機 ~/.claude/projects 的對話紀錄，產出可瀏覽的 HTML 報告：token 用量、快取效率、subagent 使用狀況、skill 使用狀況，以及最花錢的那幾段 prompt。想知道錢花在哪裡，看這個。
/plugin install session-report@claude-plugins-official
28receipts官方 Plugin
產出個人的使用成果報告：你做出了什麼、進了哪些專案、每個專案佔你用量的比例。設計用途是拿去跟主管證明這筆錢花得值得，或是自評用。
/plugin install receipts@claude-plugins-official

29using-superpowersSuperpowers
教 Claude 怎麼判斷該叫出哪個 skill。沒有這個，其他 skill 常常裝了但不會被觸發——先裝這個，其他才會動起來。
30writing-skillsSuperpowers
寫出會被正確觸發的 skill。重點在 description 欄位怎麼寫，因為那是 Claude 判斷要不要載入的唯一依據。附帶一份用 subagent 測試 skill 的方法。
31brainstormingSuperpowers
把模糊的需求問成明確的規格。它會反過來問你問題，直到需求收斂成可以動工的程度。直接叫它寫程式跟先跑一輪這個再寫，產出品質差很多。
32writing-plansSuperpowers
把規格拆成一份逐步可執行的計畫文件。
33executing-plansSuperpowers
照著計畫一步一步跑完，中途不會自己改主意跳步驟。brainstorming → writing-plans → executing-plans 是一條完整的鏈，三個一起用效果最好。
34subagent-driven-developmentSuperpowers
把任務分派給不同的 subagent 各做各的，內建 code review 環節。
35dispatching-parallel-agentsSuperpowers
多個代理平行處理不同的工作。適合彼此不相依的任務。
36explanatory-output-style官方 Plugin
在輸出裡加上對實作選擇與程式碼模式的說明，模擬已經停用的 Explanatory output style。想邊做邊學的時候開，趕時間的時候關。
/plugin install explanatory-output-style@claude-plugins-official
第 6 層 · 驗證與信任

做完之後
憑什麼相信它做對了

37test-driven-developmentSuperpowers
紅燈綠燈重構的完整 TDD 循環。先寫會失敗的測試，再寫讓它通過的程式碼。
38systematic-debuggingSuperpowers
四階段找出真正原因：重現、隔離、定位、驗證修復。它底下還帶了三份參考文件（root-cause-tracing、defense-in-depth、condition-based-waiting），會在需要的時候自動載入。這三份不是獨立 skill，裝不了也不用裝。
39verification-before-completionSuperpowers
收工前強制驗證，避免修完沒測就說做完了。
40requesting-code-reviewSuperpowers
主動要求檢查，附帶一份 code reviewer 的角色設定。
41receiving-code-reviewSuperpowers
接住檢查意見並確實修正，而不是敷衍過去。
42security-guidance官方 Plugin
針對 Claude 生成的程式碼做安全檢查。三層機制：編輯時的模式比對警告、停止時的 LLM diff 審查、commit 時的代理審查。涵蓋注入攻擊、XSS、SSRF、寫死的密鑰等 25 種以上的漏洞類型。只要你會把 AI 寫的程式碼推上線，這個是必裝。
/plugin install security-guidance@claude-plugins-official
幾個實際使用上的提醒

裝之前
先知道這五件事

裝太多會互相打架。Skill 是靠 description 觸發的，裝了 42 個之後，語意接近的 skill 會搶同一個任務。建議依專案性質分批裝，不要一次全開。
Plugin 和 Skill 的成本不一樣。Skill 在待機時只佔約 100 個 token（只載入名稱與描述），被觸發才載入完整內容。Plugin 如果帶 MCP server，那個 server 的工具定義是常駐的，開太多會吃掉 context。
官方 repo 明講這些是示範用途。anthropics/skills 的 README 寫著這些 skill 是為了展示與教學，實際行為可能與你在 Claude 產品裡遇到的不同，正式用途前請自己測過。文件類的四個（docx / pdf / pptx / xlsx）是例外，那是產品裡實際在跑的版本。
Skills 需要付費方案。免費方案沒有 Skills 功能。
清單會變。官方 repo 隨時在加減內容，這份是實際 clone 驗證後的結果。你自己跑一次 marketplace 指令再看列表，是最準的做法。
