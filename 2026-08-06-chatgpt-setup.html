2026 年 7 月 9 日之後，OpenAI 把原本的 Codex 桌面 App 改成新版 ChatGPT 桌面 App，裡面同時放進三個模式。舊版桌面 App 更名為 ChatGPT Classic，還可以繼續用。

對話、查詢、想法發散
你想「知道」某件事
Work
長流程、跨檔案、跨工具的知識工作
你想「拿到」某個東西

你想「跑起來」某個東西
模式你要的東西是典型任務
Chat一個答案解釋概念、改一段文案、查資料、腦力激盪

各模式的可用範圍
項目桌面 App網頁手機
Chat可用可用可用
Work所有方案可用Plus 以上Plus 以上
Codex可用選不到可從 Remote 分頁查看桌面端的對話

【回答方式】

2. 需要多步驟的任務，用編號列出，每一步要能直接執行。

記憶要不要開

開的好處：它會累積你的偏好、專案背景、慣用格式，長期下來回答越來越貼。開的成本：舊資訊會殘留，你三個月前的專案設定可能還在影響今天的回答。

我的做法：開著，但每個月進 設定 → 個人化 → 記憶 看一次，把過期的刪掉。

Part 5 · Work

最多人用不好
的一段

Chat 的用法是問一個問題，拿一個答案。Work 的用法是給一個目標，拿一份成品。你用問問題的方式去用 Work，等於開了一台卡車去買一瓶醬油。

一個合格的 Work 指令要有四件事
輸入：它可以用哪些資料、檔案、工具
任務：要它做什麼，分成幾個階段
產出：交付物的形式與格式
標準：什麼樣算做完了
✕ Chat 式的問法（Work 會給你一份很平庸的東西）幫我分析我的 LinkedIn。
✓ Work 式的問法
【輸入】
我的 LinkedIn 個人檔案（我會貼上連結或截圖），
以及我 Google Drive 裡的「作品集」資料夾。

【任務】
第一階段：分析我目前的檔案，找出定位不清楚、成果沒有量化、關鍵字缺漏的地方。
第二階段：對照我這個產業近半年的職缺描述，找出我還沒展現的能力。
第三階段：把上面兩項整合成一份 30 天行動計畫。

【產出】
一份試算表格式的 dashboard，欄位包含：
行動項目 / 所屬階段 / 預估耗時 / 影響程度（高中低）/ 完成標準 / 建議週次

【標準】
每一個行動項目都要具體到我明天就能開始做。
不要出現「優化個人品牌」這種無法執行的項目。
總項目數控制在 15 到 20 個。
一內容選題資料庫
Work · 選題資料庫
【輸入】
搜尋近 90 天內，[你的主題領域]這個領域在中文社群平台上討論度較高的話題。
同時參考我 Notion 裡「過往貼文成效」資料庫的數據。

【任務】
1. 整理出 30 個潛在選題
2. 每個選題標註：主題分類、預估受眾共鳴度、我是否已經寫過類似的
3. 對照我過往成效好的貼文，找出共同的選題特徵
4. 依據那些特徵，從 30 個裡面挑出最值得優先做的 10 個

【產出】
一份試算表，欄位：選題 / 分類 / 優先序 / 建議切入角度 / 一句話 Hook / 參考資料連結

【標準】
每個 Hook 都要能單獨成立，不用讀完整篇也看得懂在講什麼。
資料來源要附連結，不確定的地方標註出來。
二競品內容拆解
Work · 競品拆解
【輸入】
我會提供 3 到 5 個同領域帳號的連結。

【任務】
1. 逐一分析每個帳號的內容結構：選題方向、貼文格式、發文頻率、視覺風格
2. 找出他們共同在做、但我沒做的事
3. 找出他們都沒做、而且有機會做起來的空白區
4. 針對空白區，提出 3 個我可以切入的具體內容方向

【產出】
一份簡報，一頁一個帳號的拆解，最後三頁放空白區分析與切入建議。

【標準】
分析要基於實際觀察到的內容，不要用泛用的行銷術語填充。
每一個切入建議都要附一個具體的貼文範例標題。
三長影片轉多平台素材
Work · 一稿多形式
【輸入】
我會貼上一份逐字稿。

【任務】
1. 抓出這份逐字稿裡資訊密度最高的 5 個段落
2. 每個段落分別改寫成：IG 輪播貼文大綱、Threads 短文、短影音腳本
3. 每一種形式都要符合該平台的閱讀習慣，不要一稿多投

【產出】
一份文件，用標題分成 5 個區塊，每區塊內含三種形式的成品。

【標準】
輪播貼文大綱要標明張數與每張的核心訊息。
Threads 短文控制在 120 字以內。
短影音腳本要包含前 3 秒的鉤子與鏡頭建議。
四週報與檢討
Work · 週報
【輸入】
我的 Google Calendar 本週紀錄，
以及我 Notion 裡「本週任務」資料庫。

【任務】
1. 統計我這週實際花在各類工作上的時間比例
2. 對照我原本規劃的優先序，找出時間分配跟目標不一致的地方
3. 列出這週未完成的項目，並判斷是因為時間不夠還是優先序被排擠
4. 提出下週三個具體的調整建議

【產出】
一份文件，含一張時間分配的圖表。

【標準】
調整建議要具體到「把 X 改成 Y」，不要出現「提升專注力」這類建議。
五定期任務

Work 可以排定期任務，讓它固定時間自己跑。

Work · 每週一自動跑
每週一早上 9 點執行：

搜尋上週[你關注的領域]的重要更新，
來源限定官方部落格、官方文件、以及該領域主要媒體。

整理成一份簡報，格式：
- 這週最重要的 3 件事，每件 3 句話說明
- 對我的工作可能造成的影響
- 我這週要不要做什麼調整

不確定的資訊標註出來，附上所有來源連結。
⚠️ Work 的兩個限制：① 它會跑很久，複雜任務可能跑數十分鐘，開始跑之後就去做別的事，不要盯著看 ② 它吃額度，Work 與 Codex 共用用量，不需要交付物的任務，用 Chat 就好。

那就是該做 Skill 的訊號。Skill 是一份可重複使用、可分享的工作流程，把一個任務的做法打包起來：指令、範例、參考檔案、規則，甚至可以包含程式碼。安裝之後，遇到相符的任務 ChatGPT 會自動套用，你也可以在對話裡打 @ 直接呼叫它。

⚠️ 方案限制先確認：Personal Skills 目前主要開放給 ChatGPT Business、Enterprise、Healthcare、Edu 方案。獨立的 Skills 可在桌面 App、Codex CLI、IDE 擴充功能使用；打包成 Plugin 的 Skills 則可在網頁、桌面、手機的 Chat 與 Work 使用。桌面版與網頁／手機版的 Personal Skills 要各自新增，不會自動同步。
哪些流程適合做成 Skill
流程為什麼適合
檢查貼文是否符合品牌規範規則固定、每次都要跑

分析短影音腳本的結構有明確的評分維度
整理研究資料有固定的摘要格式
寫合作提案有固定的段落結構
判斷標準：這件事你做過三次以上，而且每次的做法都一樣。

建立後安裝，用真實任務測試幾次，再回頭修

看起來像裝飾
其實解決一個真問題

Pet 是一隻動畫小夥伴，浮在桌面上顯示任務狀態。你同時開了五個長任務，哪一個跑完了、哪一個在等你回覆、哪一個卡住了，掃一眼就知道。

狀態意思
執行中正在跑，你不用管
需要你回覆它在等你決定
已完成可以去看結果了
卡住了出問題，需要你處理
多個對話同時有動靜時，它會優先顯示需要你回覆的那一個，接著是卡住的、完成的、執行中的。
開啟方式
桌面 App：底部的個人資料選單 → Pets，或 設定 → Pets
選一隻內建的
在輸入框打 /pet，或用指令選單的 Wake Pet 叫它出來。要收起來再打一次 /pet
網頁版：設定 → 個人化 → Pet → 選擇寵物。網頁版的 Pet 出現在支援的 Work 對話裡，沒有浮動視窗、沒有活動列、沒有 /pet 指令。
做一隻自己的

設定 → Pets → Create your own pet。App 會自動安裝內建的 hatch-pet Skill、重新載入 Skills、然後開一個新對話。你在那個對話裡描述你想要的角色就行。

自訂 Pet 描述
幫我做一隻寵物。

外型：[描述你想要的角色，例如：一隻圓滾滾的橘色小貓，戴著一頂棒球帽]
風格：簡單、線條乾淨，縮到很小也看得清楚
背景：透明

需要下列四種狀態的動畫：
- 執行中：專心工作的樣子
- 需要回覆：抬頭看向使用者
- 已完成：開心的動作
- 卡住了：困惑的表情

不要加上任何文字、logo、品牌標誌或真人形象。
太複雜的話叫它簡化
把這隻寵物簡化成一個清楚的剪影，保留[主要特徵]，
去掉細節裝飾。維持透明背景，不要加文字或背景場景。
自訂 Pet 存在你的電腦本機，不會同步到網頁版。做好之後回 設定 → Pets 按 Refresh 就能選到。如果你的作業系統開了減少動態效果，Pet 會顯示靜態圖而不是動畫。
