01Handy · 取代 Wispr Flow ｜ 語音輸入難度低
取代什麼：Wispr Flow。雲端語音輸入服務，需要網路連線，語音送到遠端伺服器處理。
這是什麼

免費、開源、完全離線的語音輸入工具。按下快捷鍵、講話、放開，文字直接出現在游標所在的位置，不管你當下是在寫 email、填表單，還是在跟 AI 對話。

用 Rust 寫成，MIT 授權。完全離線是它的架構設計，不是一個可以關掉的選項：沒有雲端模式、不需要帳號、不需要網路。支援 macOS、Windows、Linux 三個平台，同一套程式碼。

GitHub · cjpais/Handy
安裝方式
macOS
brew install --cask handy
Windows
winget install cjpais.Handy
Linux 與其他安裝方式，到 GitHub Releases 頁面下載對應的檔案。
怎麼用
下載語音模型。首次開啟時會要你選一個 transcription model。Whisper 系列通用性最好；如果你用的是 Apple Silicon 的 Mac，Parakeet 系列在速度上有明顯優勢。模型會下載到本機，之後就不再需要網路。
設定快捷鍵。預設是 push-to-talk（按住講、放開停）。建議選一個平常不會誤觸的組合鍵。
測試三種情境。分別在文字編輯器、瀏覽器輸入框、以及終端機裡各試一次。有些應用程式對文字插入的支援度不同，先確認你最常用的那幾個都正常。
進階：Handy 支援接上外部模型做文字潤飾，可以串 OpenAI、Anthropic、Groq、OpenRouter，或本機的 Ollama。要注意的是，一旦接上雲端 API，語音轉出來的文字就會送出去了——如果你選它就是為了完全離線，這個功能不要開。
取捨
輸出接近逐字稿。標點會加，但不會幫你把「呃」「就是那個」清掉，也不會依據你在哪個 app 調整語氣。Wispr Flow 那種「講得亂七八糟、出來很漂亮」的體驗，Handy 沒有，除非你自己接上潤飾模型。

如果你的使用情境是「講完直接送出」，這個落差會有感。如果你本來就會再修一輪，那影響不大。
02anarlog · 取代 Granola ｜ 會議記錄難度中
取代什麼：Granola。會議記錄工具，不派機器人進會議，但轉錄與摘要在雲端處理。
這是什麼

本地優先的 AI 會議記錄工具。直接擷取你電腦的系統音訊，不會以參與者的身分出現在會議名單裡。你在會議中隨手打的片段筆記，會後由 AI 整理成結構化的摘要。

用 Rust + Tauri 寫成，MIT 授權。預設設定下 Whisper 轉錄在本機跑、摘要也在本機跑，唯一的對外連線是版本更新檢查。每場會議以 Markdown 檔案存在本機磁碟上。

⚠️ 名稱要特別注意：這個專案先叫 Hyprnote，後來改名 char，現在叫 anarlog。原本的 hyprnote.com 現在會導向團隊的另一個產品，不是這個工具。搜尋的時候請認 anarlog 或 GitHub 上的 fastrepl 這個帳號。
GitHub · fastrepl/anarlog官網 · anarlog.so
安裝方式

從官網或 GitHub Releases 下載安裝檔。支援 macOS（Apple Silicon）、Linux、Windows。

怎麼用
給系統音訊權限。macOS 會要求螢幕錄製或音訊擷取權限，這是擷取系統聲音的必要條件。
下載本機模型。Whisper 用於轉錄，內建的 HyprLLM 用於摘要，兩者都在本機跑。
改變做筆記的習慣。這是最關鍵的一步，也是多數人沒做對的地方。這個工具的設計前提是「你會邊聽邊打片段」——你打「新版儀表板 - 時程有問題」，它會結合逐字稿把這句擴寫成完整的、有前後脈絡的記錄。如果你整場什麼都不打，摘要品質會明顯下降。
（選用）接上更強的模型。如果覺得本機摘要不夠好，可以在設定裡指定任何 OpenAI 相容的端點：OpenAI、Anthropic、Gemini、OpenRouter，或本機的 Ollama、LM Studio。接雲端模型代表逐字稿會送出去，自己權衡。
取捨
改名造成的混亂是實質成本。你搜尋教學文章時會撞到三個名字的資料，其中不少已經過時。社群討論串也散在不同名稱底下。

設定過程比 Granola 明顯多幾個步驟：權限、模型下載、筆記習慣調整。Granola 是裝完就能用，這個不是。
03Perplexica / Vane · 取代 Perplexity Pro ｜ AI 搜尋難度高
取代什麼：Perplexity Pro。AI 搜尋引擎，查詢記錄儲存在對方伺服器上。
這是什麼

自架的 AI 答案引擎。你問一個問題，它先透過 SearXNG 去搜真實網路，把結果依相關性重新排序，再交給你指定的語言模型生成帶引用來源的答案。MIT 授權，完全免費，沒有付費方案、沒有授權金鑰、沒有席次上限。

⚠️ 名稱要特別注意：2026 年 3 月改名為 Vane，GitHub repo 和 Docker image 都換成了 Vane，但工具本身完全沒變。多數人還是用 Perplexica 這個名字在搜尋。
GitHub · ItzCrazyKns/Perplexica
安裝方式

需要先安裝 Docker。單一容器版本已內建 SearXNG，不需另外部署搜尋引擎：

單一容器啟動
docker run -d \
  -p 127.0.0.1:3000:3000 \
  -v perplexica-data:/home/vane/data \
  --name perplexica \
  --restart unless-stopped \
  itzcrazykns1337/vane:latest
這行指令的重點：127.0.0.1:3000 這個寫法會把服務綁在本機，不會暴露到公開網路。如果你是裝在自己電腦上，維持這樣最安全。啟動大約需要 30 秒，然後開 http://localhost:3000。
怎麼用
跑設定精靈。第一次開啟會要你選模型供應商。可選 OpenAI、Anthropic、Gemini、Groq、Ollama、LM Studio 等。想要完全免費就選 Ollama 接本機模型；想要速度和品質就接雲端 API。
認識三種速度模式。Speed（快）、Balanced（日常）、Quality（深度研究）。Quality 模式會拉更多來源、跑更多推理，適合真的要查資料的時候用，但慢也貴。
用 Focus Mode 縮小範圍。這是它比一般 AI 搜尋好用的地方——Academic 模式只搜學術來源、YouTube 模式只搜影片、Reddit 模式只搜討論串。查專業問題時把範圍縮掉，雜訊會少非常多。
設成瀏覽器搜尋引擎。把下面這行加進瀏覽器的自訂搜尋引擎，之後就能從網址列直接查。
瀏覽器自訂搜尋引擎網址
http://localhost:3000/?q=%s
取捨
模型成本要自己承擔。接雲端 API 就是按 token 計費；接本機模型就是吃你的硬體。用 Ollama 跑 7B 模型的話，一台普通桌機大概 5 到 15 秒出一個答案，比 Perplexity 慢。

沒有官方手機 app。基本安裝也不含圖片生成。

要維護一個 Docker 容器。不會 Docker 的話，這個是六個裡面門檻最高的。
04Cline · 取代 Cursor ｜ AI 寫程式難度中
取代什麼：Cursor。AI 程式編輯器，訂閱制，程式碼經過對方的後端。
這是什麼

VS Code 的開源擴充套件，Apache-2.0 授權。它不是自動補全工具，是一個 agent：你描述任務，它讀你的專案結構、提出計畫、寫檔案、跑指令、看錯誤訊息、再修，每一步都要經過你按核准。

模型完全由你決定。支援 30 多個供應商，包含 Anthropic、OpenAI、Google Gemini、AWS Bedrock、OpenRouter、DeepSeek、Mistral、Groq，以及本機的 Ollama 與 LM Studio。

GitHub · cline/clineVS Code Marketplace
安裝方式

在 VS Code 按 Ctrl+Shift+X（macOS：Cmd+Shift+X）開啟擴充套件面板，搜尋 Cline，發布者是 saoudrizwan。安裝後左側活動列會出現 Cline 圖示。

怎麼用
選供應商並填 key。點面板右上的齒輪，設定 API Provider，貼上你的 API key。key 會存在 VS Code 的 SecretStorage 裡，不會以明文寫進設定檔。
接本機模型的設定（不需要 API key）
API Provider：Ollama
Base URL：http://localhost:11434
Model：從偵測到的清單選，或直接輸入模型名稱
Context Window：至少 32K
⚠️ Context Window 一定要調到 32K 以上，這是最多人踩的坑。Agent 工作流要同時裝著計畫、多個檔案內容、和指令輸出，預設的 context 很快就滿了，模型會開始「忘記」前面在做什麼。用本機模型時，另外把設定裡的 Use Compact Prompt 打開，可以大幅減少系統提示佔用的空間。
從 Plan Mode 開始。Cline 有 Plan 和 Act 兩個模式。Plan 模式下它只讀檔案、問問題、提計畫，不會動任何東西。先在這個模式下把需求講清楚，確認它理解對了，再切到 Act。跳過這步直接讓它動手，是最容易產生一堆要復原的多檔案修改的做法。
建立 .clinerules。在專案根目錄建一個 .clinerules 檔案，寫進這個專案的規範：用什麼框架、命名慣例、哪些目錄不要碰、測試怎麼跑。Cline 每次都會自動讀。這個檔案花十分鐘寫，之後每一次任務都省時間。
先跑一個小任務驗證。開一個測試專案，切到 Plan Mode，輸入下面這句。它應該會回應、請求核准執行指令、然後產出結果。這一輪跑通了再交付真的工作。
驗證用的第一個任務
列出這個專案的所有檔案並說明各自的用途
取捨
這是擴充套件，不是完整 IDE。你留在 VS Code 裡，好處是所有既有設定、佈景、快捷鍵都不用動；壞處是它沒有 Cursor 那種深度整合的編輯體驗，例如整合式的 Tab 補全。

模型費用要自己付。Cursor 是一個月固定金額，Cline 是按 token 計費。一個編碼任務大約 US$0.01 到 0.10，用量少的話比訂閱便宜很多，重度使用可能反而更貴，換之前建議先估一下自己的量。

本機模型跑 agent 是硬仗。Agent 任務對模型的要求遠高於一般對話：要理解計畫、讀多個檔案、產出精確的工具呼叫、還要在長 context 中保持連貫。32B 以下的本機模型在長任務中常常會失去方向。實務上的建議是：例行工作（樣板碼、簡單重構、檔案搭建）用本機模型；跨檔案的架構性工作還是接雲端模型。
05LanguageTool · 取代 Grammarly Premium ｜ 文字校對難度低到中
取代什麼：Grammarly Premium。文法校對服務，你打的每一個字都會送到對方伺服器。
這是什麼

開源的文法、拼字與風格檢查工具，核心採 LGPL 2.1 授權，2005 年起持續開發至今。支援 25 種以上的語言，每種語言的規則由該語言的母語者社群維護。

有瀏覽器擴充套件、桌面版、以及 Microsoft Word 與 LibreOffice 的外掛。也可以自架成一台伺服器，讓所有裝置連向它。

官網GitHub開發者頁面
安裝方式 · 一般使用

直接裝瀏覽器擴充套件即可，支援 Chrome、Firefox、Safari、Edge。免費版對短文本已經很夠用。

安裝方式 · 自架伺服器

自架的意義是：你的文字完全不會離開你的機器。需要 Docker。

docker 直接跑
docker pull erikvl87/languagetool
docker run --rm -p 8010:8010 erikvl87/languagetool
docker compose
services:
  languagetool:
    image: erikvl87/languagetool
    ports:
      - "8010:8010"
    environment:
      - Java_Xms=512m
      - Java_Xmx=2g
    restart: unless-stopped
啟動後在瀏覽器擴充套件的「進階設定」裡，把伺服器網址改成 http://你的位址:8010/v2。注意這個 image 用的是 8010 埠，跟 LanguageTool 官方預設的埠不同。
怎麼用
掛上 n-gram 資料集（強烈建議）。沒有 n-gram 的話，它只能抓明顯的拼字和文法錯誤。掛上之後才能處理需要上下文判斷的情況，像是 there / their、your / you're 這類同音異義的誤用。英文的 n-gram 資料集大約 2GB，從 LanguageTool 官網下載，解壓到語言資料夾（例如 ./ngrams/en），然後掛載進容器。
掛載 n-gram 的啟動指令
docker run --rm -it -p 8010:8010 \
  -e langtool_languageModel=/ngrams \
  -v /你的路徑/ngrams:/ngrams \
  erikvl87/languagetool
加入自訂詞彙。你的品牌名、產品名、專有名詞一定會被標成錯字。花五分鐘把它們加進字典，之後的檢查結果會乾淨很多。
接進編輯器。VS Code 和 LibreOffice 都有外掛可以連到你自架的伺服器，寫作環境不用切換。
取捨
生成式改寫比 Grammarly 弱，這是最大的差異。LanguageTool 是檢查器：它告訴你哪裡錯、建議怎麼改。Grammarly Premium 那種「幫你把整段重寫成更專業的語氣」的能力，開源版本沒有。

如果你需要的是「抓錯」，這個換得很划算。如果你依賴的是「代筆」，這個補不上。

自架版本的規則庫跟雲端付費版不完全相同，付費版有一些額外的 AI 規則。
06Activepieces · 取代 Zapier ｜ 流程自動化難度高
取代什麼：Zapier。流程自動化平台，按執行次數計費，流程與憑證都存在對方帳號裡。
這是什麼

開源的流程自動化平台。Community Edition 採 MIT 授權，可以自架，執行次數不限。介面刻意做得接近 Zapier 的步驟式流程，非工程背景的人也能上手。

整合項目稱為 pieces，全部以 TypeScript 寫成並發布到 npm。它最值得注意的特性是：每一個 piece 同時也是一個 MCP server，代表 Claude、Cursor 這類支援 MCP 的工具可以直接把這幾百個整合當成工具來呼叫，不用另外寫串接。

官網GitHub安裝文件雲端版定價
安裝方式

需要 Docker、PostgreSQL、Redis。官方文件提供完整的 docker-compose 設定，建議直接照官方文件走。啟動前必須先產生兩把金鑰。

產生兩把金鑰
# 加密金鑰（32 個十六進位字元）
openssl rand -hex 16

# JWT 密鑰
openssl rand -hex 32
把產出的值分別填進 AP_ENCRYPTION_KEY 和 AP_JWT_SECRET。這兩個沒設好，服務起不來。啟動後開 http://localhost:8080，建立管理員帳號。
怎麼用
從一個真的很煩的流程開始。不要一開始就搬十個 Zap。挑一個你每週手動做三次以上的事情，像是新表單回覆進來就通知 Slack、新客戶進 CRM 就寄歡迎信，把它做完、跑順。
理解三段結構。Trigger（什麼時候啟動）→ 中間步驟（AI、條件判斷、迴圈、資料轉換）→ Action（做什麼）。跟 Zapier 的心智模型幾乎一樣。
AI 步驟自備 key。Activepieces 不對 AI 步驟另外收費，你填自己的 OpenAI、Anthropic 或 Gemini key，只付模型的 token 費用。
把 pieces 當 MCP 用。這是它獨有的價值。在設定裡開啟 MCP，你就能讓 Claude Desktop 或 Cursor 直接呼叫「寄 Slack 訊息」「寫進 Google Sheet」這類動作，不用自己寫任何串接程式碼。
先做備份再依賴它。自架代表資料是你的責任。PostgreSQL 一定要設定自動備份。流程本身是可匯出的 JSON，也記得定期匯出。
取捨
整合目錄比 Zapier 小很多。Activepieces 目前約 750 個 pieces，Zapier 是數千個等級。換之前一定要先去官方的 pieces 清單確認你要用的服務有沒有在裡面，這是最常見的踩雷點。

自架代表你要負責運行時間、重試處理、佇列監控、備份、憑證輪替。流程越關鍵，這些就越不能省。

部分企業功能（在 packages/ee 目錄底下）需要商業授權，不在 MIT 範圍內。

五件事
先確認再動手

一先確認你要的功能有沒有在裡面

這是最常見的失敗原因。特別是 Activepieces——去 pieces 清單搜尋你每天在用的那幾個服務，沒有的話這一步就不用往下走了。

二把「設定時間」算成成本

自架的工具省的是訂閱費，付出的是你的時間。一個下午的設定加上每個月一小時的維護，換算成你的時薪之後，可能比訂閱還貴。這個帳要自己算，而且對不同的人答案不一樣。

三先確認資料能不能搬出來

換過去之前先確認新工具能不能匯出。Activepieces 的流程是 JSON、anarlog 的筆記是 Markdown 檔案，這代表你未來要再換也走得掉。這比「現在功能多不多」更重要。

四並行跑兩週再停舊的

不要當天訂完就退訂。兩個工具同時用兩週，確認新的真的接得上你的流程，再去停扣款。

五「開源」不等於「免費」，也不等於「都一樣」

授權有差別：MIT 和 Apache-2.0 幾乎沒有限制；LGPL 對修改後再散布有要求；有些專案的核心開源但企業功能另計。個人使用通常都沒問題，商業使用前建議自己看一次 LICENSE 檔案。

組合建議

三種常見情境
直接照著配

情境一 · 我只是想少付一點錢，不想碰技術

換 Handy 和 LanguageTool 就好。兩個都是裝完即用，沒有伺服器要顧。這兩筆訂閱一年加起來省下的金額，已經是有感的數字。

情境二 · 我的工作有保密需求，資料不能出去

Handy（語音完全本機）＋ anarlog（會議完全本機）＋ Cline 接 Ollama（程式碼不外流）＋ LanguageTool 自架（文字不外流）。這四個組起來，敏感內容從頭到尾不離開你的機器。這是這份清單裡最有價值的組合。

情境三 · 我要建自己的 AI 工作流

Activepieces 當中樞，把它的 pieces 開成 MCP，讓 Claude 或 Cursor 直接呼叫。再接上 Perplexica 做內部搜尋。這個組合的門檻高，但做起來之後，整條流程都是你自己的，不受任何廠商的定價或政策變動影響。

最後

這份清單的重點
其實不是省錢

省下的訂閱費是實在的，但真正的差別在於：資料傳去哪、用哪個模型、記錄留多久、什麼時候會被拿去訓練——這些原本是別人幫你決定的預設值，換過來之後變成你自己的選擇。

代價是你要花時間設定，而且有些功能確實會失去。上面每一個工具我都把取捨寫出來了，沒有藏。
