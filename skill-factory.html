這份教學要解決的問題

Claude 不是不強
是每次都從零開始

你有沒有遇過這種情況：

  • 每次叫 Claude 寫 Email，都要重新解釋一次你的語氣和格式要求
  • 每次叫 Claude 做 FAQ，輸出的品質忽好忽壞
  • 你知道 AI 可以幫你省時間，但每次都要花大量時間「調教」它

解法是 Claude Code 的「技能（Skill）」——放在技能資料夾裡的 .md 檔案，Claude 執行任務前會先讀它：輸出格式是什麼、語氣標準是什麼、哪些規則必須遵守、範例長什麼樣。

核心概念
一個技能檔案 ＝ 一個任務類型的完整說明書。你不用每次重新解釋，Claude 讀完直接照著走。
為什麼用 NotebookLM 來寫 Skill？

手寫一份好的 skill.md 很花時間、容易漏細節。NotebookLM 的強項是只根據你提供的來源回答、不捏造——所以它很適合：從你的現有資料萃取規則 → 整理成 Claude 看得懂的格式 → 輸出一份可直接使用的 skill.md。

一句話：你提供資料，NotebookLM 幫你把規則文件化，Claude 照著執行。

STEP 2請 NotebookLM 撰寫 skill.md
目標讓 NotebookLM 根據你的來源資料，生成一份結構完整的技能說明文件。
核心 Prompt 模板 · 貼進 NotebookLM
請根據我上傳的所有來源資料，幫我撰寫一份給 AI 助理使用的技能說明文件（skill.md）。
這份文件的目的是讓 AI 在執行「[你的任務類型，例如：撰寫電子郵件]」時，能夠完全依照我的風格與格式標準輸出結果。

請包含以下章節：
1. 任務概述（這個技能是做什麼的）
2. 輸出格式規範（結構、長度、段落安排）
3. 語氣與風格原則（必須遵守 + 絕對禁止）
4. 必填資訊清單（每次執行前需要提供的資訊）
5. 輸出範例（直接從來源資料中擷取一個最佳範例）
6. 常見錯誤與避免方式

請只根據我上傳的來源資料來撰寫，不要自行補充或推測我沒有提供的內容。
調整重點
  • 把 [你的任務類型] 換成實際任務，例如「撰寫品牌電子報」「回覆客戶詢問」
  • 缺章節就追問：「請補充第 X 章節的細節」
  • 規則不夠清楚就追問：「請把第 X 條規則說得更具體，並舉例說明」
輸出品質檢查清單
清楚說明這個技能的使用場景
輸出格式有具體的結構描述（不是模糊的「保持清楚」）
語氣規範有正反兩面的例子
有至少一個完整的輸出範例
有說明「不能做什麼」

「品牌電子報」
完整 skill.md 範例

一份完整的 skill.md 長這樣。把【】換成你的資訊，直接放進技能資料夾。

email-newsletter.md · 完整範例
# 品牌電子報撰寫技能

## 任務概述
撰寫符合 [你的品牌名稱] 風格的週報電子報，發送對象為訂閱者，目的是分享本週最有價值的 AI 工具資訊，並維持與訂閱者的連結感。

## 輸出格式規範
- 主旨行：15 字以內，含數字或具體承諾
- 開場：1-2 句，直接切入本週主題，不要寒暄
- 主體：3 個段落，每段不超過 100 字
- 每段結構：現象/問題 → 具體解法或工具 → 你可以怎麼用
- 結尾：1 句話，引導讀者採取一個行動（點擊/回覆/試試看）
- 署名：[你的名字] + 一句話個人定位

## 語氣與風格原則
必須：
- 口語、直接，像在跟朋友說話
- 有具體的數字或案例
- 結論放在前面，細節放後面
禁止：
- 「希望這封信對你有幫助」類的客套話
- 超過一個以上的行動呼籲
- 過度使用感嘆號

## 每次執行前需提供
1. 本週主題（一句話描述）
2. 要介紹的工具或方法名稱
3. 這個工具最具體的一個使用場景

## 輸出範例
主旨：本週這個 Claude 設定，幫我省了 3 小時

## 常見錯誤
- 輸出太長：主體每段嚴格控制在 100 字以內
- 語氣太正式：如果感覺像「公告」，重新用口語改寫
- 行動呼籲超過一個：只保留最重要的那一個
常見問題 + 快速開始

開始前
你可能想問

我不用 Claude Code，只用 Claude.ai，適用嗎？
Claude.ai 的 Projects 可以達到類似效果——把技能文件貼進 Project 的「自訂指示」。不過 Claude Code 的 skill.md 系統支援多個技能並行，管理更彈性。
NotebookLM 生成的 skill.md 品質不好怎麼辦？
① 增加更多高品質範例來源（特別是輸出範例）② Prompt 裡更明確指定結構 ③ 分段生成——先寫格式規範、再寫語氣原則、最後寫範例。
一份 skill.md 應該多長？
通常 500–1500 字最適合。太短規則不夠清楚；太長 Claude 可能無法完整吸收。
可以讓多個技能同時生效嗎？
可以。Claude Code 會自動判斷哪個技能與當前任務最相關；想明確指定就說「請同時參考 X 技能和 Y 技能」。
