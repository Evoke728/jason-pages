DAY 1開始上路安裝
目標在你的設備上裝好 Claude，建立你的 AI 基礎架構。
Step 1｜下載 Claude 桌面版 App

前往 claude.ai 註冊帳號，下載桌面版 App（Mac / Windows 都有）。

建議用桌面版而非網頁版——桌面版支援更多進階功能，後續設定也更方便。
Step 2｜建立你的四個 Project 資料夾

進入 Claude → 點左側「Projects」→ 建立以下四個 Project：

📁 About Me
放你的個人背景檔案，讓 Claude 認識你
📁 Projects
放你目前在進行的工作或專案
📁 Templates
放你常用的 Prompt 模板
📁 Resources
放參考資料、SOP、產品說明等
為什麼要這樣做？Claude 的 Project 功能可以讓你在每個對話中自動載入特定背景資料。設定好之後，你就不用每次都重新介紹自己和你的工作。
Day 1 Checklist

DAY 3做真正的工作執行任務
目標讓 Claude 從「回答問題」變成「幫你執行任務」。

切換工作模式：很多人的用法是「問問題 → 得到答案 → 自己去做」。更有效率的是「給 Claude 真實文件 → 讓它直接幫你產出結果」。

任務 1｜上傳文件，讓 Claude 幫你處理
可上傳：會議錄音逐字稿、合約或報告 PDF、競品截圖或文字、你的草稿。
上傳文件後，貼這段
這是我們上週的會議記錄。請幫我：
1. 整理出所有待辦事項，並標明負責人
2. 列出還沒有結論的討論點
3. 摘要整個會議的重點，不超過 150 字
任務 2｜讓 Claude 分析競品
貼上競品文字後，接這段
以下是 [競品名稱] 的官網文案：
[貼上競品文字]

請幫我分析：
1. 他們主打的核心賣點是什麼？
2. 他們針對的目標客群是誰？
3. 和我們的產品相比，他們的差異化在哪？
4. 他們用了哪些說服技巧？

DAY 4串接一切MCP
目標透過 MCP 連接器，讓 Claude 直接讀取和操作你的工作工具。

什麼是 MCP？MCP（Model Context Protocol）是讓 Claude 連接外部工具的橋樑。簡單說：裝了 MCP，Claude 就能直接幫你操作 Google Drive、Gmail、Notion 等工具，不需要你複製貼上。

目前最實用的 MCP 連接器
Google Drive
讓 Claude 讀取你的雲端文件、試算表、簡報
Gmail
讓 Claude 幫你讀信、整理信件、起草回覆
Notion
讓 Claude 讀取和新增你的 Notion 頁面
Slack
讓 Claude 讀取頻道訊息、幫你寫回覆
Asana
讓 Claude 查看和建立任務
GitHub
讓 Claude 讀取 code、幫你 review PR
怎麼安裝
打開 Claude 桌面版
點左下角設定（齒輪）→「Integrations」或「連接器」
選你想連接的工具
按照指示完成授權
建議先裝這兩個：Google Drive（最多人用、立即有感）、Gmail（讓你的 Email 工作流直接提速）。
裝好之後怎麼用
連接 Google Drive 後
幫我找上個月所有和 [客戶名稱] 相關的文件，
列出每份文件的標題和最後修改日期。
連接 Gmail 後
幫我整理今天收到的所有信件，
分類成「需要我回覆」「只是通知」「可以忽略」三類。
Day 4 Checklist

實際用 Claude 操作看看，感受「不需要複製貼上」的差異

DAY 5完全解鎖Claude Code
目標用 Claude Code 讓 Claude 直接操作你的電腦，自動完成重複性工作。

什麼是 Claude Code？它是一個讓 Claude 直接存取你電腦檔案系統的工具，可以讀取整理檔案、執行批量操作、建立自動化腳本定期跑任務。不需要會寫程式——你用中文告訴它你想做什麼，它自己寫程式、自己執行。

場景 1｜自動清理下載資料夾
對 Claude Code 說
幫我整理桌面的「下載」資料夾。
規則：
- 圖片檔（jpg、png、gif）→ 移到「圖片」子資料夾
- 文件檔（pdf、docx、xlsx）→ 移到「文件」子資料夾
- 壓縮檔（zip、rar）→ 移到「壓縮檔」子資料夾
- 超過 6 個月沒開過的檔案 → 移到「待刪除」子資料夾
場景 2｜批量重新命名檔案
對 Claude Code 說
我有一堆截圖檔，名稱都是「截圖 2024-xx-xx」這種格式。
請幫我按照日期順序重新命名成「screenshot_001」「screenshot_002」這樣的格式。
檔案位置：[你的資料夾路徑]
場景 3｜建立每週自動執行的任務
對 Claude Code 說
幫我建立一個每週一早上 8 點自動執行的任務：
1. 掃描「工作」資料夾，列出上週新增的所有檔案
2. 把清單存成一個 txt 檔，命名為「週報_[日期].txt」
3. 放到「週報」資料夾裡
怎麼安裝 Claude Code
確認電腦有裝 Node.js（nodejs.org 免費下載）
打開終端機（Mac：Terminal；Windows：命令提示字元）
輸入下方指令安裝
安裝完成後輸入 claude 啟動
終端機指令
npm install -g @anthropic-ai/claude-code
第一次啟動會要求輸入 Anthropic API Key，到 console.anthropic.com 申請即可。

附錄 C · 常見問題

開始前
你可能想問

Claude 免費版可以做這些事嗎？
大部分功能免費版都能用。MCP 連接器和 Claude Code 需要付費版（Pro 方案，月費約 $20 USD）。如果你每天都在用，這個投資非常值得。
我的資料上傳到 Claude 安全嗎？
Anthropic 有明確的資料隱私政策。企業敏感資料建議使用 Claude Team 或 Enterprise 方案，有更強的資料保護。
每次開新對話都要重新設定嗎？
不需要。只要你在設定好的 Project 裡開對話，Claude 會自動讀取你放進去的所有背景資料。
Claude 和 ChatGPT 差在哪？
兩個都很強，適合不同任務。Claude 在長文件處理、指令遵循和繁體中文輸出上表現特別穩定，這也是傑森所長主要推薦 Claude 的原因。
