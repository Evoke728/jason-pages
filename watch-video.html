Part 1 · 為什麼有效

影片只有兩種東西
畫面和文字

一支影片拆開來看只有兩層：畫面（Frames）——螢幕上的圖表、數據、標題、字卡；聲音（Transcript）——講者說出來的話。

大多數「影片摘要工具」只抓第二層逐字稿。問題是，很多影片一半的重點根本不在嘴巴裡，而在畫面上——一張趨勢圖、一個數字、一句螢幕字卡，逐字稿全部漏掉。

這個方法兩層都抓
用 yt-dlp 把影片下載下來
用 ffmpeg 每隔幾秒截一張圖（Frames），同時抽出音軌
拿到帶時間戳的逐字稿（有字幕就直接用，沒字幕就用 Whisper 轉）
把「截圖 ＋ 逐字稿」一起交給 Claude

所以 Claude 看到的是完整的影片——它可以告訴你「第 3 分 20 秒那張圖顯示什麼」「講者在哪個時間點放了哪個數據」。

一句話差別
別的工具讓 Claude「讀」影片，這個方法讓 Claude「看」影片。
Part 2 · 安裝設定

一步一步
含每一行指令

你需要：Claude Code（terminal / 桌面版都可）、兩個免費老工具 yt-dlp（下載影片）＋ ffmpeg（處理畫面與音訊），以及選用的一組 Groq API Key（只有影片完全沒字幕時才用到）。

步驟一先裝好 yt-dlp 和 ffmpeg
macOS（用 Homebrew）
brew install yt-dlp ffmpeg
Windows（用 winget）
winget install yt-dlp.yt-dlp
winget install Gyan.FFmpeg
裝完後在 terminal 輸入 yt-dlp --version 和 ffmpeg -version，有跳版本號就成功。第一次執行時技能通常也會自動補齊缺的東西，但先裝好最省事。
步驟二在 Claude Code 裡安裝技能

這個技能叫 claude-video（開源，作者 bradautomates），透過「外掛市集（marketplace）」安裝，兩行指令：

在 Claude Code 執行
# 第一行：把市集加進來
/plugin marketplace add bradautomates/claude-video
# 第二行：安裝技能
/plugin install watch@claude-video

裝好後 Claude Code 會顯示「Ready to use」，接著就能用 /watch 了。

用 Codex / Cursor / Copilot 的話，改用這行裝：
npx skills add bradautomates/claude-video -g
⚠️ 提醒：這是第三方開源工具，不是 Claude 官方內建。指令與用法以 github.com/bradautomates/claude-video 的 README 為準——工具偶爾改版，裝之前掃一眼最新說明最保險。
步驟三（選用）設定 Groq API Key

這步只有處理沒字幕的影片時才需要。

到 console.groq.com 註冊（免費，不用綁信用卡）
在 API Keys 頁面產生一組 key
把它加到環境變數（見下方）
macOS / Linux（加到 ~/.zshrc 或 ~/.bashrc）
export GROQ_API_KEY="你的_key"
設定好之後重開 Claude Code 就生效。
Part 3 · 基礎用法

只有一個動作
貼上連結，下指令

用法 A｜看完整支影片
看整支
/watch https://www.youtube.com/watch?v=影片ID

Claude 會下載、截圖、抓逐字稿，然後你就能直接問它影片內容。

用法 B｜只看某一段（省時間、省 token）
給起訖時間，只看那一小段
/watch https://www.youtube.com/watch?v=影片ID --start 00:35 --end 01:30

只想分析「開頭鉤子」或某個關鍵段落時超好用，也不浪費 token。

用法 C｜看沒有字幕的影片
手機原始影片 / Loom / IG Reel 等
/watch <影片連結或本機檔案路徑>

這些通常沒內建字幕，技能會自動改用 Whisper（透過你設定的 Groq key）把聲音轉成文字，你不用多做什麼。

Part 4 · 真實成本

成本分兩塊
轉錄 ＋ 看畫面

第一塊｜轉錄：有字幕免費，沒字幕也很便宜

多數 YouTube 影片本來就有免費字幕，技能直接抓，轉錄成本趨近於零。真的沒字幕才用 Groq 轉：

項目費用
Groq Whisper Large v3 Turbo每小時音訊約 $0.04
OpenAI Whisper（同類對照）每小時約 $0.36
Groq 免費層一般人用不完
第二塊｜看畫面：這才是長影片的主要成本

真正會花的不是轉錄，是截圖餵給 Claude 時吃掉的 token——影片越長、抓越多張，Claude 讀圖就越花。好在技能會依影片長度自動控制張數，不會真的每幾秒截一張塞爆：

影片長度自動抓幾張
30 秒以內約 30 張
1–3 分鐘約 60 張
3–10 分鐘約 80 張
10 分鐘以上封頂約 100 張
超過 10 分鐘的長片，封頂 100 張畫面會變得比較稀疏。想省就用 --start / --end 只看關鍵段落（見 Part 3 用法 B）；真要看全片每個畫面，才需要開更花 token 的完整模式。
白話結論
短影片幾乎免費，長影片主要花在「Claude 讀畫面」而不是轉錄——只看你要的那一段，成本就壓得很低。

Part 5 · Prompt 包（核心）

6 組我自己在用
處理完影片直接貼

以下 6 組是我實際在跑內容時用的。處理完影片後直接貼給 Claude，把 【】 換成你的需求。

1拆解爆款影片的鉤子
用在：看到一支數據很好的影片，想搞懂它前 3 秒為什麼抓得住人。
Prompt 1 · 拆鉤子
你已經看完這支影片。請專注分析「開頭前 5 秒」的鉤子設計，回答以下：
1. 逐字列出開頭講者說的每一句話（含時間戳）
2. 畫面上同時出現了什麼（字卡、畫面、動作、表情）
3. 這個鉤子用了哪些心理機制？請從這幾個角度判斷：
   - 權威感（他憑什麼讓你聽）
   - 模式中斷（哪裡打破了你的預期）
   - 資訊落差（他埋了什麼你想知道的懸念）
   - 視聽落差（畫面和聲音有沒有製造衝突感）
4. 如果我要模仿這個鉤子做自己的內容，可以怎麼改寫？給我 3 個變體。
2把長影片濃縮成重點筆記
用在：45 分鐘的演講、Podcast、教學影片，你只想要精華。
Prompt 2 · 重點筆記
你已經看完這支影片。請幫我整理成一份可以收藏的重點筆記：
1. 用一句話總結整支影片的核心論點
2. 列出 5-8 個關鍵重點，每個重點：
   - 一句話標題
   - 兩到三句說明
   - 附上出現的時間戳，方便我回去看
3. 如果影片畫面上有出現重要的圖表或數據，請單獨列出來並說明
4. 最後給我 3 個「值得深入思考的問題」
用條列式，繁體中文。
3把影片變成 IG 輪播選題
用在：你想把一支好影片的內容，改造成自己的貼文素材。
Prompt 3 · 輪播選題
你已經看完這支影片。我要把它的內容改造成我自己的 Instagram 輪播貼文。
請幫我：
1. 從影片中找出 3 個「可以獨立成篇」的選題角度
2. 每個角度給我一個「會讓人停下來滑」的封面標題（用數字或具體結果，不要問句）
3. 選出你覺得最有潛力的那一個，幫我拆成 8 張輪播的大綱：
   - 每張一句話標題
   - 標註哪張是痛點、哪張是解法、哪張是 CTA
4. 提醒我：影片裡有沒有哪個「反直覺的觀點」特別適合當鉤子？
繁體中文，語氣直接、不說教。
4競品 / 對標帳號影片分析
用在：研究別人的內容怎麼做的，找出你可以學的結構。
Prompt 4 · 對標拆解
你已經看完這支影片，這是我正在研究的對標內容。請幫我做一份拆解：
1. 內容結構：他把影片分成哪幾個段落？各段的作用是什麼？（附時間戳）
2. 留人設計：他在哪些時間點做了「防止觀眾離開」的動作？（例如：預告後面、丟問題、換場景）
3. 記憶點：整支影片最讓人記得住的一句話或一個畫面是什麼？
4. 可複製的部分：如果我要做同主題內容，有哪 3 個他的做法我可以直接借用？
5. 他沒做好的地方：有沒有哪裡其實可以更好？
繁體中文，講重點就好。
5把教學影片轉成 SOP 步驟
用在：操作教學、工具示範影片，你想要一份能照著做的文字步驟。
Prompt 5 · 轉 SOP
你已經看完這支教學影片。請幫我把它整理成一份清楚的操作 SOP：
1. 這支影片教的是「怎麼做到什麼」？用一句話說明目標
2. 把操作拆成編號步驟，每一步：
   - 具體動作
   - 如果畫面上有出現按鈕、選單、指令，請照抄下來
   - 附上對應的時間戳
3. 列出過程中他有提到的「注意事項」或「常見錯誤」
4. 我照做需要準備什麼工具或前置條件？
繁體中文，步驟要細到我可以直接照做。
6把長影片改成短影音腳本
用在：把一支長影片裡的精華片段，改寫成 30-60 秒的短影音腳本。
Prompt 6 · 短影音腳本
你已經看完這支影片。請從裡面挑出「最適合做成短影音」的一個片段，
幫我改寫成一支 45 秒的短影音腳本：
1. 先告訴我你選了哪一段、為什麼（哪裡最有梗或最有價值）
2. 寫出腳本，包含：
   - 前 3 秒鉤子（一句話，要夠猛）
   - 中段內容（分鏡＋口播逐字稿）
   - 結尾 CTA
3. 標註哪些地方適合放字卡、哪些地方畫面要換
4. 給我一個適合的貼文標題
繁體中文，口語、有節奏感。
Part 6 · 常見問題

卡住時
看這裡

一定要會寫程式嗎？
不用。安裝時複製貼上指令就好，之後使用只是貼連結。整個過程你不需要看懂任何一行程式碼。
影片很長會不會很慢或很貴？
有字幕的話幾乎是即時且免費。真的很長又沒字幕時，可以用 --start / --end 只處理你要的那一段，省時間也省錢。
Claude 自己不是能看影片嗎？為什麼要這個？
Claude 本身沒有原生的影片能力。這個方法聰明的地方，就是把影片拆成「圖片 + 文字」——這兩種格式 Claude 本來就非常擅長處理。
只能用 YouTube 嗎？
不是。YouTube、Instagram、Loom、本機影片檔都可以。沒字幕的用 Whisper 轉即可。
下載失敗、或它叫我「登入確認不是機器人」怎麼辦？
YouTube 有時會擋自動下載。兩招通常能解：① 先更新 yt-dlp——Mac 打 brew upgrade yt-dlp，其他系統打 yt-dlp -U，版本太舊是最常見原因；② 還被擋就帶上瀏覽器的登入狀態，在下載指令加 --cookies-from-browser chrome（chrome 換成你的瀏覽器）。這是 yt-dlp 本身的限制，跟這個技能無關。
要裝的是哪一個技能？
bradautomates/claude-video（開源、MIT）。在 Claude Code 執行 /plugin marketplace add bradautomates/claude-video，再 /plugin install watch@claude-video 就好。它是第三方工具，用法以 GitHub repo 的 README 為準。
