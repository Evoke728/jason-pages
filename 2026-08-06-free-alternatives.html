部分使用者回報過草稿遺失的狀況，重要專案記得階段性匯出備份。

03螢幕錄影 · Loom → OBS Studio唯一零條件
Loom→OBS Studio開源，無額度、無浮水印、無時長限制
官方網站官方文件
為什麼這組值得換：OBS 是開源軟體，沒有額度、沒有浮水印、沒有時間長度限制，也沒有付費層。這是這份清單裡唯一完全零條件的一項。代價是它的預設介面對新手不友善，要花一次時間設定。設定完之後就一勞永逸。
一次設定，之後都不用再碰
建立場景。在「場景」欄位按加號，建立三個場景：全螢幕教學、只有我、螢幕加人像。之後錄影切換場景就好
加入來源。「顯示器擷取」抓整個螢幕／「視窗擷取」只抓單一應用程式／「視訊擷取裝置」加攝影機／「音訊輸入擷取」加麥克風
設定輸出格式。「設定」→「輸出」→ 錄影格式選 mkv
畫質設定。「設定」→「影片」→ 基本與輸出解析度都設 1920x1080，FPS 設 30
設定快捷鍵。「設定」→「快捷鍵」→ 把「開始錄影」和「停止錄影」設成不會誤觸的組合鍵
⚠️ 第三步很關鍵：格式一定要選 mkv。如果錄影中途當機，mkv 檔案還救得回來，mp4 會整個壞掉。錄完再用 OBS 的「檔案」→「重新封裝錄影」轉成 mp4。
教學影片不需要 60 幀，設 30 檔案會小一半。進階：要錄短影音的話另外建一個場景，把基本解析度改成 1080x1920，來源用「顯示器擷取」加上裁切濾鏡，只留下畫面中間需要的區域。
實際限制
沒有雲端連結分享功能，錄完要自己上傳到 Drive 或 YouTube。

沒有自動字幕、沒有 AI 剪輯，這些要另外處理。

首次設定大約要花 30 到 60 分鐘。
什麼時候該回去付費：團隊協作需要即時分享連結、需要觀看數據追蹤、需要影片內留言功能的時候。Loom 的價值在流程而不在錄影本身。

05自動化 · Zapier → n8n（自架）自架才免費
Zapier→n8nSustainable Use License，fair-code 而非 OSI 開源
官方網站官方文件授權條款說明
⚠️ 先講清楚「免費」的定義。實際意思是：

· 你自己架在自己的伺服器上，軟體授權費為零，工作流數量、執行次數、使用者人數都不設限
· 你要付的是伺服器、資料庫、網域、SSL 的費用，以及維護的時間
· 內部業務使用完全沒問題
· 把 n8n 包裝成自己的產品賣給第三方，這個要另外談商業授權
· n8n Cloud 是託管服務，那是付費的

所以這一項的正確說法是「自架免費」，不是「免費」。
三種自架方式，難度由低到高

方式一 · 本機 Docker（適合先試水溫）

裝好 Docker Desktop 之後跑這兩行
docker volume create n8n_data

docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
瀏覽器打開 http://localhost:5678 就進去了。限制：電腦關機工作流就停了，只適合測試和手動觸發的任務。

方式二 · VPS 自架（適合真的要跑排程）：租一台入門級 VPS，裝 Docker，搭配 PostgreSQL 當資料庫，用 Caddy 或 Nginx 處理 SSL。跑得動大部分個人與小團隊的工作流。

方式三 · 一鍵部署平台：Railway、Render 這類平台有 n8n 的部署模板，點幾下就好，適合不想碰終端機的人。成本略高於自己租 VPS。

06語音生成 · ElevenLabs → MiniMax Audio
ElevenLabs→MiniMax Audio中文語音自然度在同級工具裡表現不錯
官方入口定價頁開發者文件
適合的情境：短影音旁白、Podcast 開場、教學影片的配音、中英雙語內容的語音版本。
上手三步驟
註冊帳號，進入 Text-to-Speech 頁面
從音色庫挑一個，或用 Voice Design 用文字描述生成一個專屬音色
貼上稿子，調整語速、音高、情緒參數，試聽後匯出
幾個調參的實用心得
  • 標點決定停頓：逗號、句號、破折號會直接影響斷句。稿子寫給人看和寫給 TTS 唸，標點要重新處理一次
  • 專有名詞用注音或拼音硬寫：模型唸錯品牌名或人名的時候，直接把字換成同音的常見字，唸出來是對的就好
  • 語速先設 1.0 再微調：大部分情況 0.9 到 1.1 之間就夠，超過會有機械感
