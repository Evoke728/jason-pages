這不是魔法
是讓你看清問題

先說清楚——這套 Prompt 不會憑空幫你變出錢。它做的事很簡單：把你心裡那些「好像怪怪的、但說不上來」的地方，攤開來給你看。

很多生意不是賺不到錢，是一直在漏錢。而漏錢的地方，通常是你每天看著、卻已經看到麻木的東西。

✗ 多數人會這樣用
丟一句「幫我看看我生意有什麼問題」，然後得到一堆教科書廢話。

因為你沒給它真東西，它只能給你罐頭答案。
✦ 這套的做法
先讓 Claude 當顧問，逼它反問你，再讓它診斷、最後給你一週的補洞清單。

順序對了，它才看得到你看不到的洞。
先講一句重話
你越誠實，他越能幫你。數字不敢攤、問題藏著掖著——Claude 也救不了你。
STEP 1 · 餵資料

先讓它
當你的顧問

第一步不是叫它給答案，是叫它當一個會反問你的顧問。把你的事業現況丟給它，讓它先搞懂全貌。

PROMPT 1 / 3 — 設定角色 + 餵資料
你現在是一位資深的營運顧問，專門幫中小事業和個人創業者，找出「正在悄悄漏錢」的地方。

我會把我的事業現況給你，請你像一個真正的顧問一樣——先聽、再問，不要急著給建議。

我的事業：【一句話講你在做什麼】
每月營收大概：【金額】
主要成本有：【人事 / 廣告 / 租金 / 工具訂閱 / 進貨…列出來】
我花最多時間在：【描述】
我最賺錢的客戶或產品是：【描述】

請先不要給建議。
先問我 5 個「身為顧問，你最需要釐清」的問題，幫你看清我的全貌。
為什麼要它先問你？因為真正的漏洞藏在細節裡。它問得越多，後面診斷得越準——把它的問題老實回答完，再進下一步。
STEP 2 · 找漏洞

叫它
不客氣地說真話

資料夠了，這一步讓它直接點出三個最可能在漏錢的地方。記得加上「講真話、不要安慰我」——不然它會客氣到沒用。

PROMPT 2 / 3 — 找出三個漏洞
根據我剛才的回答，請幫我找出 3 個最可能「正在漏錢」的地方。

每一個漏洞，請告訴我：
1. 它是什麼、為什麼會發生
2. 它每個月大概在吃掉我多少錢、或多少時間
3. 我「這禮拜」就能做的一個具體動作

請用直白、不客氣的方式講。
我要的是真話，不是安慰——該戳的地方就戳。
你大概會看到這幾種洞：一筆重複付、但其實沒人在用的費用；你最賺的客戶，反而被你花最少時間；還有你以為的成本，其實是另一個地方在燒。
STEP 3 · 補洞

把診斷
變成這週的行動

看清楚不夠，要動。最後一步，挑一個最快能補、效果最明顯的洞，讓它幫你拆成七天就能做完的小動作。

PROMPT 3 / 3 — 七天補洞清單
從這 3 個漏洞裡，挑一個「最快能補、而且效果最明顯」的。

幫我列一份 7 天的補洞行動清單：
- 每天只給我一個小動作
- 動作要具體到「我今天打開電腦就能做」
- 不要喊口號，不要寫「思考一下」這種

我照著做就好。
重點不是工具多強，是你有沒有真的動。把第 1 天的動作，今天就做掉——這份診斷才算沒白做。
