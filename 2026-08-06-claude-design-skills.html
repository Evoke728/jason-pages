01frontend-design · 基礎美學方向Anthropic 官方
做什麼：在寫 code 之前，強制 Claude 先決定三件事：這個東西的目的、受眾、以及要走哪一種美學方向（brutalist、maximalist、retro-futuristic、luxury、playful 等）。方向決定之後才開始寫。

它同時封鎖了一批預設選項：Inter、系統字體堆疊、紫色到藍色漸層、卡片網格。這些是模型的預設反射動作，擋掉之後它才會去找別的解法。
Skill 裡面有一條規則我很喜歡：要求它每次至少冒一個能被說明理由的美學風險。
GitHub · anthropics/skills
安裝
npx skills add anthropics/skills --skill frontend-design -g

# 也可以用 plugin 方式安裝整個 marketplace
/plugin marketplace add anthropics/skills
怎麼用
用 frontend-design skill，幫我做一個線上課程的 landing page。
主題是給上班族的 AI 工具課，受眾是 28 到 40 歲、有預算但沒時間的人。
先跟我說你選的美學方向跟理由，我確認之後再寫 code。

02design-taste-frontend · 行銷頁品味層社群
做什麼：這個 skill 常被叫做 taste-skill，那是 repo 的名字。repo 裡面現在預設的 skill 名稱是 design-taste-frontend（v2 改寫版），舊版保留為 taste-skill-v1。
旋鈕控制什麼調高的效果
variance版面變化度非對稱排版、破格構圖
motion動態量進場動畫、捲動觸發

預設值偏向表現力強的方向。它會先讀你的 brief，判斷這是什麼類型的頁面、給誰看、要什麼語氣，然後自己決定旋鈕的位置，開始寫之前會用一句話跟你講它的判斷。守備範圍寫得很明確：landing page、作品集、改版。後台介面、設定頁那類東西它不管。

跟其他 skill 的設計哲學相反：多數重量級 skill 會做成薄索引、需要時才載入細節，這個押注在「規則要一起讀才有意義」。你的專案 context 很吃緊的話，這件事要納入考慮。

這個 skill 由 Remotion 團隊自己維護，載入三十幾份規則檔，涵蓋動畫、音訊、素材、字幕、圖表、文字、轉場、composition 管理，還有 Three.js 和 React Three Fiber 做的 3D 場景。採用薄索引架構，只在需要的時候載入對應的規則檔，比較省 context。

04impeccable · 設計總監，23 個指令Paul Bakaus
做什麼：前面三個是「開始之前給方向」，這一個是「做完之後進場修」。它的角色是設計總監，底下有 23 個單字指令，每一個對應一種 AI 生成介面的典型失敗模式。你用一個字下指令，取代寫一長段描述。

維護者是 Paul Bakaus（jQuery UI 作者、前 Google Chrome DevTools PM），Apache 2.0 授權。
指令做什麼
/impeccable audit無障礙、效能、響應式品質檢查
/impeccable critiqueUX 檢視：層級、清晰度、情緒共鳴
/impeccable polish出貨前最後一輪：對齊、間距、細節
/impeccable distill砍掉沒有存在必要的複雜度
/impeccable bolder太安全太無聊的設計，加強力道
/impeccable quieter太吵太用力的設計，收斂
/impeccable typeset修字體選擇、層級、字級
/impeccable colorize給單色介面加策略性的顏色
/impeccable animate加有目的的動態
/impeccable delight加值得記住的小驚喜
/impeccable harden錯誤處理、國際化、邊界情況
/impeccable clarify修 UX 文案、標籤、錯誤訊息
它最重要的設計：brand 模式與 product 模式分流
行銷頁、作品集、編輯型內容走 brand，設計本身就是產品；後台、儀表板、內部工具走 product，設計服務產品。兩者的判斷標準相反，多數 skill 把它們混在一起處理，這個分開。
除了 LLM 判斷之外，它還帶幾十條確定性的偵測規則，跑起來不需要呼叫模型也不需要 API key。
GitHubimpeccable.style
安裝與初始化
npx impeccable install

# 裝完在 Claude Code 裡跑一次初始化
/impeccable init

# 用 skills CLI 安裝也可以
npx skills add pbakaus/impeccable --skill impeccable -g
⚠️ init 不能跳過。init 會問你這個介面屬於 brand 還是 product，然後寫出 PRODUCT.md，記錄受眾、品牌語氣、反面參考、色彩、字體、元件。後面每一個指令都會讀這份檔案。沒有 PRODUCT.md，所有指令都會回到通用輸出，等於白裝。
常用指令可以釘成獨立捷徑
/impeccable pin audit
釘完之後 /audit 就能直接用，不必每次打全名。
實際的迭代節奏
/impeccable critique landing

# 看它列出問題，再針對性下指令
/impeccable typeset landing
/impeccable arrange landing
/impeccable polish landing
它有一個很好的預設行為：context 不足的時候會停下來問你，不會硬猜。第一次用會覺得囉唆，那正是它跟一般 prompt 的差別。
05brandkit · 品牌識別系統社群
做什麼：組出一整套可以拿去提案的品牌識別板：logo 概念、色彩系統、字體、mockup。它的順序是先想品牌的意義，再處理美感，所以產出的東西有內在一致性，後續你做任何素材都能對回同一套系統。跟第 02 個住在同一個 repo，共用同一套反 AI 味的判斷邏輯。
GitHub · Leonxlnx/taste-skill
安裝
npx skills add Leonxlnx/taste-skill --skill brandkit -g
怎麼用（給它品牌的核心概念，不要只給形容詞）
用 brandkit，幫我做一套個人品牌識別。

品牌名：起點學院
定位：教一般人用 AI 做內容變現
受眾：想做自媒體但完全沒經驗的上班族
核心概念：起點，不是終點。第一步比完美重要。

06canvas-design · 海報平面設計Anthropic 官方
做什麼：做靜態平面作品，輸出 .png 或 .pdf。海報、封面、單頁圖像。

它的運作分兩階段，這是它跟一般 AI 生圖最大的差別：第一階段先生成一份設計哲學文件（.md），給這套美學命名，例如「Brutalist Joy」「Chromatic Silence」，然後用四到六段文字說明這個美學透過形式、空間、色彩、構圖如何展現。第二階段才根據那份哲學去畫。所以出來的東西有內在邏輯，不是隨機的風格拼貼。
它還有一個設計：會把主題當成埋在作品裡的隱性線索，懂的人會感覺到，不懂的人單純看到一幅好構圖。字體從 skill 自帶的 canvas-fonts 目錄取用。元素重疊或超出畫布邊界，它視為不可接受的失敗，會重做。

07animate · 介面動態impeccable 的一部分
做什麼：分析一個既有介面，找出「應該要有動態但目前是硬切」的地方，然後只在那些地方加。它處理進場動態、狀態變化、按鈕回饋、hover 效果。
它的核心原則
挑一個招牌時刻。全部都動的介面反而沒有重點，這個 skill 會主動抵抗那種傾向。
它同時強制幾件事：尊重使用者的 prefers-reduced-motion 設定、只用 transform 和 opacity 來保 60fps、把行動裝置的效能預算納入判斷。
安裝（裝了 impeccable 就有）
npx impeccable install

# 也可以單獨安裝
npx skills add pbakaus/impeccable --skill animate -g
怎麼用
/impeccable animate checkout

# 釘成捷徑之後可以直接用 /animate
/impeccable pin animate
⚠️ 用之前要先跑過 /impeccable init，它需要讀 PRODUCT.md 才知道這個介面的調性。
想要完全獨立、不依賴 impeccable 的動態 skill，另一個選擇是 Emil Kowalski 的版本：npx skills add delphi-ai/animate-skill --skill animate -g。那一套把「退場要比進場快」「只用 transform 和 opacity」這類原則寫成規則，路線接近但獨立運作。
